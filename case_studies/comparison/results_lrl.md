## Legend

- **Dialect**: LRL with the typed backend (Rust with LRL types mapped to Rust types) or the dynamic backend
  (Rust over a universal `Value` type). Both backends run the same checks before code generation; they differ
  only in the generated code.
- **Kind**: positive = a correct program that uses the feature (ideally accepted and run); negative = the property
  is violated (ideally rejected before running); limit = an evidence row probing what LRL can express at all.
- **Expected**: our prediction. A positive predicted COMPILE_ERROR means LRL cannot express the program;
  a negative predicted ACCEPT means the violation is not caught; a predicted BACKEND_ERROR is a known
  code-generator bug or limitation (listed in `lrl/README.md`).
- **Observed**: ACCEPT = LRL's checks passed, rustc built the generated Rust, and the binary exited with status 0
  (for `[generated Rust: ...]` rows: the build succeeded and the excerpt quotes the generated code);
  COMPILE_ERROR = rejected by LRL before code generation (diagnostic codes: F = elaborator, K = kernel,
  M = MIR); BACKEND_ERROR = LRL's checks passed but rustc rejected the generated Rust; RUNTIME_ERROR = compiled,
  then exited with a non-zero status; CRASH = the LRL compiler crashed. Limit rows: NOT_IN_PLACE = the generated
  cons constructor allocates a new cell (`Rc::new`/`Box::new`), i.e. there is no in-place update;
  NO_OPERATION_ON_REF = no declaration of the stdlib files takes a `Ref` argument, i.e. nothing reads or writes
  through a reference.
- **Match**: Observed = Expected.
- **Verdict**: positive: accepted / rejected before running / checks passed, code generation failed / failed at
  run time; negative: rejected before running / detected at run time / not detected / not detected by the
  checks, code generation failed; limit: no in-place update (new cells are allocated) / no operation reads or
  writes through a reference.
- **Excerpt**: first LRL diagnostic (or first rustc error with its location) for rejected programs; the first
  lines of output otherwise (each `print_nat` prints one line; the binary then prints `Result: <value of main>`).
